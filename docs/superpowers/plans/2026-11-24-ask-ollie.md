# Ask Ollie Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A read-only chat with Ollie that answers questions about loans, bills, savings and money, using the owner's own Groq key.

**Architecture:** A pure `buildSummary()` turns app data into a compact, pre-calculated text summary. A small Groq client sends system prompt + summary + conversation in one `chat/completions` request and maps failures to four plain error kinds. A bottom sheet hosts the conversation in component state; it is opened from the dashboard (app bar button or the owl) and from the unlocked private folder, which alone passes `includePrivate`.

**Tech Stack:** React 19, TypeScript, Zustand, Tailwind v4, Vitest (node env — pure functions and an injected `fetch` only).

**Spec:** `docs/superpowers/specs/2026-11-24-ask-ollie-design.md`

## Global Constraints

- Endpoint `https://api.groq.com/openai/v1/chat/completions`, header `Authorization: Bearer <key>`. Model constant `GROQ_MODEL = 'openai/gpt-oss-120b'` (Groq's named replacement for retired llama-3.3-70b-versatile; checked 2026-11-24).
- No built-in key anywhere in the repo or bundle. Key lives in localStorage `loan-tracker-groq-key` only; never in backups, exports or logs.
- Private loans (and the folder name) appear in a summary only when `includePrivate` is true, which only the private folder page passes.
- Overall loan totals in the summary come from the existing functions (they exclude private loans); private loans get their own block and subtotal.
- Summary budget: ≤ 24,000 characters (~6,000 tokens). Trim oldest monthly breakdowns first, then the entries window; never drop loans, bills or goals.
- Answers only: nothing in this feature writes to any store except the key.
- Conversation lives in component state; closing the sheet clears it. History sent to Groq is capped at the last 10 messages.
- Copy is sentence case. Error copy (verbatim):
  - bad-key: "Your Groq key was rejected. Check it in Settings."
  - rate-limit: "Groq's free limit is used up for now. Try again in a minute." (with `retryAfter` > 90 s: "Try again in about N minutes.")
  - offline: "No connection. Ollie needs the internet to answer."
  - failed: "Ollie couldn't get an answer. Try again."

## Review Focus

1. Dashboard chat with a private loan in the data — the loan's name, figures and the folder name must be absent from what's sent. (Task 1 test.)
2. Groq answers 200 with empty or missing `content` (reasoning models can spend the budget thinking) — must show the "failed" message, not a blank bubble. (Task 2 test.)
3. A long conversation — only the last 10 messages go out, so requests stay small. (Task 2 test.)
4. A key pasted with spaces/newlines, or an empty paste — trimmed; empty means no key. (Task 2 test on `normalizeKey`.)
5. The folder locks (app backgrounded) while the chat is open from it — the sheet must close and clear. (Task 3 browser check.)

### Task 2: Groq client and the key

**Files:**
- Create: `src/features/askOllie/groqClient.ts`, `src/features/askOllie/groqClient.test.ts`
- Create: `src/features/askOllie/askOllieStore.ts`

**Interfaces:**
- Produces (`groqClient.ts`):
  - `GROQ_MODEL`, `GROQ_URL`, `MAX_HISTORY = 10`
  - `type ChatMessage = { role: 'user' | 'assistant'; content: string }`
  - `type AskError = 'bad-key' | 'rate-limit' | 'offline' | 'failed'`
  - `type AskResult = { ok: true; answer: string } | { ok: false; error: AskError; retryAfter?: number }`
  - `buildMessages(summary: string, history: ChatMessage[], question: string): Array<{ role: 'system' | 'user' | 'assistant'; content: string }>` — system prompt, then summary as a second system message, then the last `MAX_HISTORY` of history, then the question.
  - `askGroq(opts: { apiKey: string; summary: string; history: ChatMessage[]; question: string; fetchImpl?: typeof fetch }): Promise<AskResult>` — body `{ model, messages, temperature: 0.2, max_completion_tokens: 1024 }`.
  - `errorMessage(error: AskError, retryAfter?: number): string` — copy from Global Constraints.
  - `normalizeKey(raw: string): string | null`
- Produces (`askOllieStore.ts`): `useAskOllieStore` with `apiKey: string | null`, `setKey(raw: string): void` (via `normalizeKey`), `removeKey(): void`; localStorage `loan-tracker-groq-key`, reads/writes wrapped in try/catch.

- [ ] **Step 1: Write failing tests** (`groqClient.test.ts`, fake `fetchImpl` returning `new Response(...)`):
